# 03. 콘텐츠 파이프라인 — Story Seed 에서 5개 이상 뽑기

## 1. 단위: Story Seed
`content/seeds/seed_NNN.md`
```
# Seed 017 — 코코가 처음으로 카페를 혼자 운영한다
장소: 문라이트 카페 | 필수 등장: 리아, 왕자 | 떡밥: 왕자 신분 힌트 2
의상 후보: c010 앞치마룩, c011 캐주얼, c012 원피스
사건 한 줄: 주문이 밀리고, 낯선 손님(왕자)이 조용히 도와준다
결말 고정: 별조각 +120, 호감도 +1 | 질문: "저 사람, 카페 일을 왜 이렇게 잘하지?"
히든: 재플레이+c012 → 레오와 예나가 카페 밖에서 마주침
```

## 2. 파생 (시드 1개 → 최소 5개)
| 산출 | 파일 | 규격 |
|---|---|---|
| 게임 스테이지 | `data/stages/stage_NNN.json` | 02 스키마 |
| 일러스트 1~2 | `content/images/sNNN_*.png` | Hero, 9:16 과 1:1 두 크롭 |
| 쇼츠 대본 2~3 | `content/shorts/sNNN_a.md` | 15~20초, 3~4컷, 마지막 컷 로고+리아 |
| 블로그 1 | `content/blog/sNNN.md` | 세계관 일기("리아의 오늘") 또는 개발기("[1인 개발] …") |
| 히든 에피소드 | stage JSON `hidden` | 1장면 |

## 3. 쇼츠 대본 템플릿
```
제목: 왕자님이 처음으로 리아를 알아본 순간
컷1 (0-4s) 상황 자막 + 리아 Hero
컷2 (4-10s) 대사 2줄 (자막 + TTS)
컷3 (10-16s) 사건 + 반응 표정(Sticker)
컷4 (16-20s) 질문 자막 + "다음 이야기는 게임에서" + 로고
```
반복 규칙: 모든 쇼츠 마지막 컷은 동일(로고+리아). 노출의 반복이 IP 다.

## 4. 주간 리듬
월: 시드 2~3개 확정 → 화~수: 스테이지 JSON + 일러 → 목: 쇼츠·블로그 → 금: 게임 업데이트 + 게시.
스테이지가 게임에 들어가기 전에 쇼츠가 먼저 나가도 된다("다음 이야기는 게임에서").

## 5. AI 에게 주는 방식
- 텍스트: `01_WORLD_BIBLE.md` §2·§5 + 시드 → "이 구조를 유지하며 40자/6줄 규칙으로 대사를 써라".
- 이미지: §4 프롬프트 템플릿 + 리아 마스터 참조.
- AI 는 **표현**을 만든다. 구조(보상·다음·떡밥 순서)는 사람이 시드에서 정한다.

## 6. 보관 (저작권 대비)
`content/images/_raw/` 에 AI 원본 + 프롬프트 txt. 사람이 수정한 파일은 `_edit/`. 최종은 루트.
