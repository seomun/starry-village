# 01. 세계관 바이블 + 캐릭터 DNA + 아트 규칙

AI(텍스트·이미지)에게 매번 주는 "신분증". 여기 없는 설정은 AI 가 지어내도 **정본이 아니다**.
확정되면 이 문서에 적고, `DECISIONS.md` 에 D-번호를 남긴다.

---

## 1. 세계 — 스타리빌리지 (Starry Village)

별이 유난히 가까이 보이는 작은 도시. 패션·카페·학교·파티·여행·쇼핑의 예쁜 일상.
그 뒤에 왕궁·오래된 가문·숨겨진 신분·오래된 사건이 숨어 있다. 판타지 30% / 일상 70%.

아이에게 세계관을 **설명하지 않는다**. "리아가 오늘 새 옷을 샀대!" 가 세계관이다.
100개를 보면 "나 스타리빌리지 알아" 가 되는 것.

### 장소 (반복 등장 → 썸네일만 봐도 알게)
| 장소 | 기능 | 공통 소품 |
|---|---|---|
| 스타일 스튜디오 | 옷·헤어·액세서리 (1호 무대) | 별 모양 거울, 리본 |
| 문라이트 카페 | 디저트·수다·왕자와 우연 | 초승달 간판 |
| 플라워 가든 | 꽃·동물·비밀 대화 | 별꽃 |
| 스타 하우스 | 리아의 방 | 창밖 큰 별 |
| 별빛 우체국 | 편지·부탁·사건의 시작 | 별 도장 |
| 광장/왕궁 | 파티·페스티벌·정체 공개 | 별 문양 깃발 |

공통 시각 요소(모든 이미지에 하나 이상): 별 / 우편봉투 / 작은 리본 / 별 문양.

## 2. 캐릭터 DNA

### 2-1. 리아 (ria) — 주인공 ★확정 우선
```
얼굴: 계란형, 큰 눈(핑크브라운), 작은 코, 작은 입, 살짝 통통한 볼
머리: 긴 웨이브, 따뜻한 갈색, 왼쪽에 작은 별 헤어핀(시그니처)
체형: Hero 6등신 / Game 3등신, 가늘고 긴 실루엣
대표색: 로즈핑크 · 크림 · 골드
기본 의상: 크림 원피스 + 핑크 리본
성격 한 단어: 예쁨·호기심. 말투: 밝고 짧다. "어? 저 사람…"
절대 안 바뀌는 것: 머리색, 머리길이, 눈색, 얼굴형, 별 헤어핀, 등신
```

### 2-2. 레오 (prince) — 2026-09-15 GPT 시트로 확정 (D9)
```
겉: 평범한 고등학생(18). 차분·다정·책임감, 가끔 허당. 물건 떨어뜨리고 리아에게 도움 받음
속: 왕궁/대가문의 숨겨진 신분 + 능력. 위기 때 무심한 한마디로 해결
외형: 은백색 짧은 머리(살짝 흐트러짐), 파란 눈. 평소엔 교복/캐주얼, 정체 드러날수록 네이비·골드 왕자복
시그니처: 왕관 장식, 블루 리본, 보석 브로치. 스토리 소품: 낡은 회중시계(별 문양)
대표색: 네이비 · 하늘색 · 아이보리
말투: 짧고 담담. "그쪽은 건드리지 않는 게 좋을 텐데."
정체 공개 페이스: 00_MASTER §4-4. 절대 한 번에 공개하지 않는다
```

### 2-3. 예나 (rival) — 17세
```
예쁨(리아와 다른 종류: 날카로움), 도도함, 강한 승부욕, 겉은 차갑고 속은 따뜻. 리아에게 경쟁심, 레오에게 관심
비밀: 레오의 과거를 일부 안다 → 중반부터 "너는 아직 저 사람을 몰라"
외형: 긴 검은 생머리, 보라 눈, 보라 리본 헤어핀, 네이비 교복+체크 스커트. 대표색: 퍼플·라벤더
말투: 짧고 콧대 높음. "흥. 그런 옷으로 파티에?"
평면적 악당 금지. 세계관 비밀의 열쇠 보관자
```

### 2-4. 현 (goofy) — 17세
```
겉: 활발·장난기·의리파. 대단해 보이려 하지만 진짜 허당. 코미디 담당, 리아 짝사랑
외형: 갈색 짧은 머리, 초록 눈, 헤드폰, 흰 후드+검정 카고팬츠, 큰 배낭. 늘 뭔가 들고 있다가 떨어뜨림
대표색: 그린 · 화이트
말투: 큰소리. "내가 지켜주겠다!" → 넘어짐
```

### 2-5. 소라 (star) — 16세, 리아의 단짝
```
순수·긍정·호기심, 가끔 허당. 리아 곁에서 내레이션·힌트·질문 담당("그런데… 왜 이름을 알았을까?")
외형: 연갈색 긴 웨이브, 노란 눈, 파란 베레모+리본, 노란 멜빵 원피스, 크로스백
대표색: 옐로 · 스카이블루
※ id 는 `star` 유지(코드·데이터 호환). 원래 "별 요정" 설정은 D9 로 폐기.
```

### 2-6. 확장 친구(2호 이후, 필요 시): 코코(카페·먹보), 미미(정원·그림), 나나(소심·호기심)

## 3. 아트 규칙

### 3-1. 화풍 "Soft Story Kawaii"
- 피한다: 전형적 AI 일러(반짝이·렌즈플레어·꽃잎 폭풍), 일본 애니 그대로, 지나친 유아풍, 캐릭터마다 다른 그림체.
- 원한다: 단순한 형태 + 강한 실루엣 + 예쁜 색 + 재미있는 표정 + 작은 디테일 하나.

### 3-2. 3단 표현
| | Hero | Game | Sticker |
|---|---|---|---|
| 등신 | 6~7 | 2.8~3.5 | 1~2 / 얼굴 |
| 선 | 깨끗, 가늘게 | 두껍고 균일 | 두꺼움 |
| 음영 | 부드러운 셀 1단 | 최소 | 없음 |
| 색 | 파스텔 팔레트 | 캐릭터 대표색 3~4 | 대표색 |
| 손 | 그림 | 손가락 없음 | 없음 |
| 배경 | 있음 | 단색/투명 | 투명 |
동일 캐릭터 판정 5요소: 눈색 · 머리색 · 헤어스타일 · 시그니처 소품 · 대표색.

### 3-3. 드레스업용 파츠 레이어 (Game Form) — 순서는 z-index
```
01 body  02 shoes  03 bottom  04 top / dress  05 bag  06 hair_back  07 face
08 hair_front  09 hair_acc  10 necklace  11 expression(overlay)
```
파일: `assets/characters/ria/game_body.png` … `assets/costumes/{costume_id}/{layer}.png`.
캔버스 360×640, 캐릭터 기준 박스 240×420 중앙. 모든 파츠 PNG 는 같은 캔버스 크기로 저장(정렬 문제 제거).

### 3-4. 표정 6종 id
`joy` `surprise` `shy` `angry` `sad` `love`

## 4. 이미지 프롬프트 템플릿 (캐릭터 부분 고정, SCENE 만 교체)

```
CHARACTER: Ria
IDENTITY: long wavy warm brown hair, large pink-brown eyes, small star hair pin on the left,
soft oval face, small nose and mouth, slim petite silhouette, rose pink / cream / gold palette
STYLE: soft story kawaii, pastel colors, clean thin lineart, soft cel shading, no lens flare,
no sparkles overload, simple background
DO NOT CHANGE: hair color, hair length, eye color, face shape, star hair pin, body proportion
FORM: [Hero 6-7 heads | Game chibi 3 heads thick outline flat color | Sticker face only]
SCENE: <이번 장면. 의상 id 와 장소를 적는다>
REFERENCE: <리아 마스터 이미지 첨부>
```
새 캐릭터를 "예쁜 소녀" 로 새로 뽑지 않는다. **좋은 리아 한 장을 다음 생성의 출발점으로 계속 쓴다.**

## 5. 텍스트 규칙 (AI 대사 생성 시)
- 한 줄 40자 이내, 스테이지당 6줄 이내, 마지막 줄은 질문.
- 존댓말/반말: 리아·소라 반말, 레오 담담한 존댓말, 예나 반말, 현 반말 외침.
- 금지: 신체 접촉 묘사, 폭력, 외모 비하(예나의 견제는 옷·태도에 한정).
- 의상별 variant 는 **첫 두 줄만** 다르고 사건·결말은 같다.
